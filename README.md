## 🌟 The Reality & The Mission

Across Pakistan, over **150,000 low-fee private schools** educate more than **25 million children** from working-class families on razor-thin operating budgets. Modern EdTech consistently fails them because:
1. **The "No Student Phones" Rule**: Non-premium schools strictly prohibit students from bringing mobile devices to campus, and parents cannot afford 1-to-1 tablets.
2. **The Infrastructure Reality**: Daily load-shedding and spotty cellular internet break cloud-only software. If a system requires continuous Wi-Fi to take attendance, it dies within two days.
3. **The Language Barrier**: Most school software forces complex, English-only interfaces that alienate parents and create friction for teachers.
4. **The VIP LMS Divide**: Elite school networks (Beaconhouse, LGS, City School) spend lakhs on enterprise learning management systems and charge parents monthly subscription fees.

### 💡 The Solution: Ustad-AI
**Ustad-AI** is a "Teacher-First" AI platform engineered to run **entirely on a single smartphone** belonging to the teacher, combined with a **zero-install Web Parent Portal** and an automated **24/7 WhatsApp AI Agent**. 

Using **Alibaba Cloud DashScope (Qwen-Max & Qwen3-VL)** and embedded local **SQLite**, it brings cutting-edge AI into low-resource classrooms without requiring student devices and completely **free of any subscription fees**.

## 🚀 Key Feature Suite

### 1. 👨‍🏫 Teacher Modules
* **AI Handwritten Paper & Test Grader (Qwen3-VL)**: Point the camera at messy student handwriting. Qwen3-VL reads pencil derivations, verifies working step-by-step against curriculum standards, scores 0–10, and outputs encouraging bilingual feedback.
* **1-Tap Punjab SNC Lesson Planner & Printable Worksheets**: Directly aligned with the Punjab Single National Curriculum. Generates a 40-minute classroom roadmap plus a printable 5-question PDF worksheet in 5 seconds.
* **30-Second Morning Homework Inspection Register**: Rapid notebook roll call (`[✓ Done / ✗ Incomplete]`) with 1-tap automated Urdu WhatsApp alerts to parents of incomplete work.
* **Teacher-Isolated Timetable**: When logged in as a teacher, the schedule automatically locks down to show only that teacher's assigned periods and classes.
* **Interactive AI Classroom**: Voice viva oral exams, camera-based STEM scavenger hunts, and whole-class voice roleplays with Quaid-e-Azam, Allama Iqbal, and Sir Isaac Newton over classroom Bluetooth speakers.

### 2. 👨‍💼 Admin & Principal Modules
* **AI Conflict-Free Master Timetable**: Generates clash-free schedules across Nursery to Class 10 with designated break periods. Filterable by Class, Teacher, or Subject with PDF export.
* **AI Terminal Report Cards (Printable PDF)**: Computes letter grades and averages. Qwen-Max drafts personalized pedagogical character appraisals in authentic Nastaliq Urdu script.
* **Marks & Examination Leaderboards**: Overall class rankings + subject tabs with responsive horizontal-scrolling tables.
* **Daily Morning Assembly AI Hub**: Curates Hadith of the Day and moral thoughts, speaking aloud over school speakers via TTS.
* **Comprehensive Fee Ledger & PDF Challan Generator**: Tracks paid statuses, fee balances, and prints official bank challans.

### 3. 👨‍👩‍👧 Dual Parent Engagement Architecture
* **In-App Mobile Parent Portal**: Dedicated login role on the mobile application for parents using their registered phone number.
* **Zero-Install Web Parent Portal**: Parents can simply open [`/parent/view`](https://ustad-ai-backend.onrender.com/parent/view) in any mobile or desktop web browser.
* **1-Tap Universal Sibling Switcher**: Automatically links all children enrolled under that family phone number across classes (e.g. *Hamza in Class 5* and *Bilal in Class 5*).
* **24/7 Dedicated WhatsApp School Agent (`+92 307 7486000`)**: Compact floating button in Parent Mode allowing parents to query the AI assistant regarding fees, admissions, school rules, and queries at any hour.

## 🛡️ Role-Based Access Control & Offline Resilience

- **Teacher Class Scoping**: When a teacher logs in, their designated class (e.g., `Class 5`) is bound to the session.
- **Strict Data Isolation**: Oral Exams, STEM Scavenger Hunt, Whole-Class Roleplay, Class Marks, and Daily Attendance are locked to the teacher's designated class (`🔒 Designated Class`), preventing unauthorized access to other classes.
- **Admin Leadership**: School administrators and the Chairman retain universal access across all grades (Nursery to Class 10) with staff allocation toggles.
- **Local SQLite Engine**: Student rosters, marks, fee ledger records, and attendance operate 100% offline.
- **On-Device Speech & TTS**: Native Android speech recognition and synthesis run on-device without data consumption.
- **Reactive Network Banner**: Automatically detects network status and alerts teachers when operating in local offline mode vs cloud AI mode.

## ⚙️ Setup & Running

### 1. Environment Configuration
Create `.env` from the provided example templates:
```bash
# In backend/
copy backend\.env.example backend\.env
# In ustad_ai/
copy ustad_ai\.env.example ustad_ai\.env
```
Add your **Alibaba Cloud DashScope API Key** (`DASHSCOPE_API_KEY`) to both `.env` files.

### 2. Python Backend Setup
```bash
cd backend
python -m pip install -r requirements.txt
# Run the FastAPI server:
python -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
Test the backend health:
```bash
python test_api.py
```

### 3. Flutter Mobile App
```bash
cd ustad_ai
flutter pub get
flutter test
# Run on Web (Edge / Chrome):
flutter run -d edge
# Or run on connected Android phone:
flutter run -d android
```
